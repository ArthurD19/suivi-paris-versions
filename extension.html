Suivi Paris · extension

Mettre à jour l'extension dans Orion, sans recoller le code de liaison.

Ouvre cette page dans Orion, le navigateur où l'extension est installée.

  1. Si la fenêtre de l'extension a des éléments prêts à envoyer, envoie-les d'abord : une réinstallation les efface.
  2. Télécharge la nouvelle version et, dans Fichiers, range-la dans Sur mon iPhone → Orion. Télécharger l'extension
  3. Orion : ••• → Extensions, supprime Suivi Paris, touche + et choisis le fichier. Accepte les sites.
  4. Cette page se rouvre toute seule et relie l'extension : rien à recoller.
La liaison reste dans ce téléphone : elle n'est envoyée nulle part.
